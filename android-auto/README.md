# Radio Cedars — Android Auto

Android companion app for Radio Cedars.

## Goals

- Open the full Radio Cedars website on the phone.
- Provide a dedicated Android Auto media interface for browsing radio stations and controlling playback.
- Keep the Android project separate from the existing website.

## Website

https://radio-cedars.vercel.app/

## Build

The Android app will be built using GitHub Actions. Android Studio is not required on the user's computer.

## Important

Android Auto supports approved media interfaces, not unrestricted website browsing while driving. The app must follow Android Auto media app requirements.
